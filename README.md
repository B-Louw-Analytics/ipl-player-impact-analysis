# 🏏 IPL Player Impact Analysis

Revolutionizing cricket analytics with Win Probability Added (WPA) to measure which players actually change game outcomes.

## 🔬 Key Insights
- Traditional stats have weak correlation with actual impact
- Context matters more than raw runs/wickets
- Discovered hidden gem players that conventional analysis misses

## 📊 Top Impactful Players
- **Batters**: S Dhawan, RG Sharma, JC Buttler
- **Bowlers**: YS Chahal, PP Chawla, HV Patel
- **Efficiency Kings**: TH David, R Tewatia, LH Ferguson

## 🛠 Technical Stack
- Python, Pandas, SQLAlchemy
- Plotly for interactive visualizations
- Streamlit for dashboard deployment
- 1,169 IPL matches analyzed (2008-2024)
